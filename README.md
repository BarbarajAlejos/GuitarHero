#  GuitarHero

Juego rítmico desarrollado como proyecto académico utilizando tecnologías web.
El proyecto busca recrear la dinámica de un juego musical tipo Guitar Hero,
donde el jugador debe interactuar con notas que aparecen siguiendo el ritmo de una canción y acumular una puntuación.

 # Objetivo

Desarrollar una aplicación web interactiva que permitiera aplicar conceptos de desarrollo frontend,
manejo de eventos, lógica de juego y diseño de interfaces.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Sistema de notas musicales.
- Interacción del jugador mediante controles.
- Sistema de puntuación.
- Sistema de vidas.
- Detección de errores durante la partida.
- Estados de juego como inicio, pausa y finalización.
- Efectos visuales y sonoros.
- Interfaz inspirada en la estética de juegos arcade.
